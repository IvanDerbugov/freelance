# 🔐 Руководство по подключению к серверу

## Данные сервера
- **IP адрес:** 185.151.240.250
- **Пользователь:** root
- **Порт:** 22 (стандартный)
- **Ключ:** мойКлючАнтонМодалка.ppk

## Способ 1: Подключение через Cursor (Рекомендуется)

### Шаг 1: Установите расширение
1. Откройте Cursor
2. Нажмите `Ctrl+Shift+X` (расширения)
3. Найдите и установите: **Remote - SSH**

### Шаг 2: Настройте SSH конфигурацию
1. Создайте папку: `C:\Users\ВашеИмя\.ssh\`
2. Создайте файл `config` в этой папке
3. Скопируйте содержимое из файла `ssh-config.txt` в этот файл
4. Замените "ВашеИмя" на ваше имя пользователя Windows

### Шаг 3: Подключитесь
1. В Cursor нажмите `Ctrl+Shift+P`
2. Введите: `Remote-SSH: Connect to Host`
3. Выберите: `anton-server`
4. Дождитесь подключения
5. Откройте папку проекта на сервере

## Способ 2: Подключение через PuTTY

### Настройка PuTTY:
1. Откройте **PuTTY**
2. В поле **Host Name:** введите `185.151.240.250`
3. В поле **Port:** введите `22`
4. В разделе **Connection type:** выберите **SSH**
5. В левом меню: **Connection → SSH → Auth**
6. Нажмите **Browse** и выберите файл `мойКлючАнтонМодалка.ppk`
7. Нажмите **Open**

## Способ 3: Командная строка (если установлен OpenSSH)

```bash
ssh -i "D:\мойКлючАнтонМодалка.ppk" root@185.151.240.250
```

## После подключения

### Работа с файлами:
- **Через Cursor:** Откройте папку проекта на сервере
- **Через терминал:** Используйте `nano`, `vim` или `code` для редактирования
- **Загрузка файлов:** Используйте `scp` или SFTP клиент

### Полезные команды:
```bash
# Просмотр содержимого папки
ls -la

# Переход в папку
cd /path/to/project

# Редактирование файла
nano filename.html
# или
code filename.html

# Просмотр файла
cat filename.html
```

## Безопасность
- ✅ Приватный ключ храните в безопасности
- ✅ Не передавайте приватный ключ другим
- ✅ Регулярно делайте бэкапы проекта
- ❌ Не оставляйте подключение открытым без присмотра

## Решение проблем

### Ошибка "Permission denied":
- Проверьте путь к приватному ключу
- Убедитесь, что ключ не поврежден

### Ошибка "Connection refused":
- Проверьте IP адрес и порт
- Убедитесь, что сервер доступен

### Ошибка "Host key verification failed":
- Удалите старую запись из `C:\Users\ВашеИмя\.ssh\known_hosts`
- Или добавьте `-o StrictHostKeyChecking=no` к команде SSH
