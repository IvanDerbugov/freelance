# Формат API для чата AI-ассистента "Наканунщик"

## Endpoint
```
POST /api/chat
```

## Формат запроса (Request)

### Headers
```
Content-Type: application/json
```

### Body
```json
{
  "messages": [
    {
      "text": "Привет! Я — AI-помощник «Наканунщик». Давайте прикинем идею для вашей праздничной рассылки? Напишите, какой у вас бизнес.",
      "isBot": true
    },
    {
      "text": "Интернет-магазин одежды",
      "isBot": false
    },
    {
      "text": "Отлично! Интернет-магазин одежды — интересная сфера! 🎉\n\nТеперь подскажите, какая цель у праздничной рассылки?\n(привлечь новых клиентов / поздравить существующих / запустить новый продукт / другое)",
      "isBot": true
    },
    {
      "text": "привлечь новых клиентов",
      "isBot": false
    }
  ],
  "step": "business",
  "userInput": "привлечь новых клиентов"
}
```

### Поля запроса:
- **messages** (array, обязательное) - Массив всех сообщений в чате (история диалога)
  - **text** (string) - Текст сообщения
  - **isBot** (boolean) - `true` для сообщений бота, `false` для сообщений пользователя
- **step** (string, обязательное) - Текущий шаг диалога. Возможные значения:
  - `"initial"` - Начало диалога (первый вопрос о бизнесе)
  - `"business"` - Пользователь указал бизнес, ожидается цель рассылки
  - `"goal"` - Пользователь указал цель, бот генерирует идеи
  - `"ideas"` - Пользователь видит идеи, ожидается email
  - `"email"` - Финальный шаг (email получен)
- **userInput** (string, обязательное) - Последнее сообщение пользователя (текст, который он только что отправил)

## Формат ответа (Response)

### Успешный ответ (200 OK)

```json
{
  "success": true,
  "data": {
    "message": {
      "text": "Супер! Сейчас подумаю и предложу идеи... 🤖✨",
      "isBot": true
    },
    "nextStep": "goal",
    "additionalMessages": [
      {
        "text": "🎁 КРЕАТИВНЫЕ ИДЕИ ДЛЯ ВАШЕЙ РАССЫЛКИ:\n\n💡 Идея 1: \"Новогодний адвент\"\nСерия писем с нарастающими бонусами и сюрпризами до праздников\n\n💡 Идея 2: \"Подарок под елку\"\nСпециальное предложение только для подписчиков с праздничным оформлением\n\n💡 Идея 3: \"История года вместе\"\nТеплое письмо с достижениями компании и благодарностью клиентам\n\n📧 Хотите получить полный план рассылки на почту? Оставьте свой email.",
        "isBot": true
      }
    ],
    "delay": 2000
  }
}
```

### Поля ответа:
- **success** (boolean) - `true` если запрос успешен
- **data** (object) - Данные ответа
  - **message** (object, обязательное) - Основное сообщение бота
    - **text** (string) - Текст ответа бота
    - **isBot** (boolean) - Всегда `true`
  - **nextStep** (string, опциональное) - Следующий шаг диалога. Если не указан, шаг остается прежним
  - **additionalMessages** (array, опциональное) - Дополнительные сообщения, которые нужно показать после задержки
    - Каждый элемент имеет структуру: `{ "text": string, "isBot": true }`
  - **delay** (number, опциональное) - Задержка в миллисекундах перед показом `additionalMessages`. По умолчанию 0

```json
  }
}
```

## Примечания

1. **История сообщений**: В запросе всегда отправляется полная история диалога (все предыдущие сообщения + новое сообщение пользователя)

2. **Шаги диалога**: Бэкенд может изменить шаг через поле `nextStep` в ответе, или оставить его без изменений

3. **Дополнительные сообщения**: Если нужно показать несколько сообщений с задержкой (например, сначала "думаю...", потом идеи), используйте `additionalMessages` с `delay`

4. **Текст ответа**: Бэкенд может генерировать любой текст ответа, используя информацию из истории сообщений и текущего шага

5. **Валидация email**: На шаге "ideas" бэкенд может проверить, что `userInput` является валидным email адресом

6. **Обработка ошибок**: Если API вернет ошибку, фронтенд покажет сообщение об ошибке пользователю
