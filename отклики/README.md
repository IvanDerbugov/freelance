## Файлы

- `заглушка.html` - основная HTML страница
- `placeholder-style.css` - стили в стиле основного сайта
- `.htaccess` - настройки сервера для оптимизации
- `README.md` - этот файл с инструкциями

## Развертывание на хостинге

1. Загрузите все файлы в корневую папку домена на хостинге
2. Убедитесь, что файл `заглушка.html` переименован в `index.html`
3. Проверьте, что файл `.htaccess` загружен корректно
4. Настройте SSL-сертификат для HTTPS

## Настройка домена

После загрузки файлов:
1. Убедитесь, что домен указывает на папку с файлами
2. Проверьте работу HTTPS (автоматический редирект настроен в .htaccess)
3. Протестируйте на разных устройствах
