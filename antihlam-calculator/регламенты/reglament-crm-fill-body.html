1. В CRM необходимо заполнять все поля, чтобы логист и водитель могли корректно вести заказ.

  2. Название сделки:

    1. Указывать понятное название по шаблону: Авито! - Домодедово - 17:30 = По заполнению - БЕЗНАЛ (Оплачено).
    2. Если заказ с Avito — в начале названия обязательно ставить отметку «Авито!».
    3. Если заказ оформлен — указывать только время начала заказа (например: 17:30 или с 14:00 до 16:00).
    4. Если заказ ещё не оформлен — указывать дату и время следующего шага (например: Перезвонить 4.11 в 16:00).
    5. Если расчёт по кубам по факту — добавлять пометку «По заполнению».
    6. Если оплата по безналу — добавлять пометку БЕЗНАЛ (Оплачено / Не оплачено).

  3. Адрес и детали:

    1. Заполнять адрес клиента точно: улица и номер дома, как в Яндекс.Картах.
    2. Указывать важные детали: подъезд, этаж, квартира, домофон.
    3. По шлагбауму выбирать один из вариантов: Нет / Сможет открыть / Не сможет открыть.
    4. По парковке выбирать один из вариантов: Бесплатная / Платная - Оплатит / Платная - Не оплатит.
    5. Добавлять другие нюансы, если есть: пронос, консьерж, кто встречает.

  4. Дата и время:

    1. Если заказ оформлен — указывать дату выполнения заказа.
    2. Если заказ не оформлен или клиент не берёт трубку — указывать дату следующего шага (сегодня / завтра / согласованный день).
    3. Указывать время начала заказа, на которое договорились с клиентом.
    4. Для статуса «Думает»: указывать время следующего звонка, ставить интервал минимум 10 минут между заявками и не ставить их на одно время.
    5. Время окончания указывать только для оформленных заказов; для статуса «Думает» поле оставлять пустым.

  5. Контакты клиента:

    1. Телефон клиента в поле подставляется автоматически.
    2. Если номеров несколько — нажать «Добавить телефон» и внести дополнительный номер в формате 79999999999.
    3. Отметить «Основной контакт» на номере, по которому можно связаться с клиентом.
    4. На мобильном номере обязательно поставить чек-бокс «СМС», чтобы ушло сообщение с контактами и информацией по заказу.
    5. На номере для переписки обязательно выбрать нужные каналы коммуникации кнопками мессенджеров: WhatsApp / Telegram / Max.
    6. В поле ФИО указывать имя клиента. Если на месте будет другой человек — добавить контакт и заполнить его имя и телефон.

  6. Описание и калькулятор:

    1. В описании заказа фиксировать все предметы с количеством и размерами, а также другие данные, влияющие на стоимость.
    2. Перед отправкой заказа логисту удалить лишнюю информацию, которая может отвлекать.
    3. Сумма в описании заказа должна совпадать с суммой из калькулятора.
    4. Все предметы, которые называет клиент, обязательно вносить в калькулятор через кнопку «Выбрать предметы».
    5. После выбора предметов обязательно выбирать тип подачи: «Подача машины» (Москва) или «Подача машины (За МКАД / ЦЕНТР)» (за МКАД или ЦАО).
    6. Если лифта нет или предмет не влезает в лифт — указать этаж, чтобы система автоматически рассчитала спуск пешком.
    7. Если выезд после 19:00 — поставить чек-бокс вечернего выезда, который добавляет 500 ₽ к стоимости.

  7. Бюджеты, ответственные и статус:

    1. Начальный бюджет заполняется автоматически после калькулятора — эту сумму нужно озвучить клиенту.
    2. Конечный бюджет заполняет водитель, который выполняет заказ.
    3. В поле «Ответственный диспетчер» выставлять себя для корректного распределения процента.
    4. Статус клиента выставлять кнопками: Сохранить / Думает / Сохранить в заказ / Отмена / Потеря.
    5. При отмене обязательно указывать в названии сделки причину отказа.
