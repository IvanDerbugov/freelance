## 📁 Структура проекта

```
MyWebsite/
├── index.html                        # Главная страница сайта
├── style.css                         # Основные стили
├── media.css                         # Адаптивные стили
├── main.js                           # Основная логика сайта
├── animation.js                      # Canvas-анимации
├── send-form.js                      # ⭐ Telegram интеграция
```

1. Пользователь заполняет форму на сайте
2. JavaScript отправляет данные в Telegram Bot API
3. Вы получаете уведомление в Telegram
4. Лог сохраняется в localStorage
5. Можно просмотреть в админ-панели
