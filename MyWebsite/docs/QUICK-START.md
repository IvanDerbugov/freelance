# 🚀 Quick Start - Telegram Integration

## 3 простых шага для настройки

### ⏱️ Время настройки: 2 минуты

---

## Шаг 1️⃣: Получите Chat ID (30 сек)

1. Откройте Telegram
2. Найдите бота **@userinfobot**
3. Напишите `/start`
4. Скопируйте число из строки `Id:` (например: `123456789`)

📸 **Пример:**
```
@userinfobot
Id: 123456789  ← Это ваш Chat ID
First: Иван
Username: @ivan
```

---

## Шаг 2️⃣: Активируйте бота (15 сек)

1. Найдите бота **@derbugov_bot**
2. Нажмите кнопку **START**
3. Готово! Бот может вам писать

---

## Шаг 3️⃣: Настройте код (30 сек)

Откройте файл `send-form.js` и замените:

```javascript
// Строка 29 - замените число на ваш Chat ID
const TELEGRAM_CHAT_ID = '6169313997'; // ← Ваш Chat ID сюда!
```

**Важно:** Используйте только цифры, в кавычках!

---

## ✅ Проверка работы (1 минута)

### Способ 1: Автоматический тест
1. Откройте `test-telegram.html` в браузере
2. Нажмите все 3 кнопки тестирования
3. Проверьте Telegram

### Способ 2: Ручной тест
1. Откройте `index.html` в браузере
2. Нажмите кнопку "Получить скидку"
3. Заполните форму
4. Отправьте
5. Проверьте Telegram

## ❓ Не работает?

### Сообщение не пришло?

**Проверьте:**
- ✅ Нажали START у @derbugov_bot?
- ✅ Chat ID правильный (только цифры)?
- ✅ Файл сохранен после изменений?
- ✅ Страница перезагружена?

### Ошибка "Forbidden: bot was blocked by the user"

**Решение:** Откройте @derbugov_bot и нажмите START

### Ошибка "Bad Request: chat not found"

**Решение:** Проверьте Chat ID - должны быть только цифры

## 💡 Дополнительно

### Отправка в группу

Хотите получать заявки в группу? 

1. Создайте группу в Telegram
2. Добавьте @derbugov_bot
3. Дайте боту права администратора
4. Получите ID группы через:
   ```
   https://api.telegram.org/bot8439270981:AAFMnuowPXV9SJuu6ydkYdG2hHW4_GT2ahI/getUpdates
   ```
5. Используйте ID с минусом (например: `-123456789`)

### Просмотр логов через консоль

Откройте консоль браузера (F12) и выполните:

```javascript
// Посмотреть все логи
console.table(FormHandler.getAllLogs());

// Экспорт в файл
FormHandler.exportLogsToFile();

// Очистить
FormHandler.clearLogs();
```
