# Создание изображения для превью в мессенджерах

## Проблема
Когда вы отправляете ссылку на сайт в мессенджерах (Viber, Telegram, WhatsApp), они автоматически создают превью, используя первое изображение со страницы, если не указано конкретное изображение.

## Решение

### 1. Создайте изображение для превью
1. Откройте файл `og-image.html` в браузере
2. Сделайте скриншот страницы (1200x630 пикселей)
3. Сохраните как `img/og-image.jpg`

### 2. Альтернативный способ (онлайн генератор)
Можете использовать онлайн генераторы:
- https://www.canva.com/create/social-media-graphics/
- https://og-image.vercel.app/
- https://www.photopea.com/

### 3. Рекомендуемые параметры изображения
- **Размер:** 1200x630 пикселей
- **Формат:** JPG или PNG
- **Содержание:** Ваше имя, профессия, краткое описание
- **Стиль:** Соответствует дизайну сайта

### 4. Проверка
После создания изображения:
1. Загрузите `og-image.jpg` в папку `img/`
2. Отправьте ссылку на сайт в мессенджер
3. Превью должно показывать ваше изображение вместо первого изображения со страницы

## Техническая информация
В HTML уже добавлены правильные мета-теги:
- `og:image` - ссылка на изображение
- `og:image:width` и `og:image:height` - размеры
- `og:image:alt` - описание изображения
- `twitter:image` - для Twitter
