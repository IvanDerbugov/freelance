Freelance — рабочий репозиторий

Портфолио и рабочий репозиторий с проектами, выполнеными на фрилансе.

О репозитории:

Здесь собраны проекты (не под NDA), в которых я участвовал. Этот репозиторий использую, когда у заказчика нет своего Git — код хранится в одном месте и доступен для заказчиков и портфолио.

Что внутри:

- **Лендинги и многосстраничники** — рекордика.рф, мебельный магазин, HandyMark, Zoreli и др.
- **LP и веб-приложения** — Наканунщик (React/Vite)
- **Email‑рассылки, баннеры, виджеты**
- **Учебные и тестовые проекты** — YandexMusic, book
